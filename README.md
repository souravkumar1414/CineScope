# 🎬 CineScope

CineScope is an AI-powered movie discovery platform that helps users find movies through semantic search, intelligent recommendations, and interactive visual insights. Instead of relying only on keywords, CineScope understands the intent behind user queries and delivers more relevant movie suggestions.


## 🚀 Features

- 🔍 AI-powered movie search
- 🎯 Semantic movie recommendations
- 📊 Interactive analytics and visualizations
- 🤖 Gemini AI integration for intelligent insights
- ⚡ Fast and responsive user interface
- 📱 Mobile-friendly design
- 🎬 Movie trend exploration


## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- Chart.js
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
- Vector Search

### AI & ML
- Google Gemini API
- Embedding-based Semantic Search

## ⚙️ Installation

### Clone the Repository

bash git clone https://github.com/souravkumar1414/CineScope.git cd CineScope 

### Install Dependencies

#### Frontend

bash cd client npm install 

#### Backend

bash cd server npm install 



## 🔑 Environment Variables

Create a .env file inside the server directory:

env MONGODB_URI=your_mongodb_connection_string GEMINI_API_KEY=your_gemini_api_key PORT=5000 



## ▶️ Running the Application

### Start Backend

bash npm run server 

### Start Frontend

bash npm start 

The application will be available at:

bash http://localhost:3000

## 💡 How It Works

1. User enters a movie-related query.
2. Gemini AI processes the query and generates semantic understanding.
3. MongoDB Vector Search finds similar movies based on embeddings.
4. Results are displayed with AI-generated insights and visual analytics.
